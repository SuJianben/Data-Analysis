# 2026-09-14 TMS 分页点击混入菜单分析

## 问题描述

- TMS 菜单分析出现 `2. oldal`、`5. oldal` 等商品列表分页标签。
- `oldal` 为匈牙利语“页面”，不属于网站头部菜单。

## 复现条件

1. 用户在 TMS 商品集合页点击分页按钮。
2. 全局点击脚本将分页 `<nav>` 识别为普通导航区域。
3. 脚本同时发送 `global_click` 与 `header_navigation_click`，分页记录进入菜单报表。

## 根本原因

- TMS 脚本使用“位于任意 `nav` 内”作为菜单事件判断条件，没有排除商品分页导航。

## 影响范围

- 仅影响 TMS 菜单分析的名称、点击总量、趋势和散点分布。
- 分页点击本身属于有效全局点击，应继续保留在全局埋点中。
- TKF 数据不受影响。

## 修复方案

- 主题埋点将分页控件标记为 `pagination`，不再发送菜单事件。
- GA4 同步层过滤 TMS 历史脚本产生的数字分页、上一页和下一页菜单标签。
- 精确清理 D1 与本机数据库中已经导入的 TMS 分页菜单行。

## 修复状态

- 状态：已修复。
- TMS 主主题 `assets/tms-global-click.js` 已发布并从 Shopify 回读，分页识别函数和 `pagination` 区域标记均已生效。
- 重新同步 2026-09-11 至 2026-09-13，共导入 676 行，Cloudflare D1 同步编号为 11。

- JavaScript 语法检查、Next.js 生产构建、TypeScript 检查和 Git 空白检查均通过。
