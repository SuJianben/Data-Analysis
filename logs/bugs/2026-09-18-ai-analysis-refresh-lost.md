# 2026-09-18 AI 分析刷新后丢失

## 缺陷

- 用户生成 AI 分析后刷新页面，结果恢复为空状态。

## 根因

- 分析页面固定向客户端传入 `initialResult=null`，没有读取已经保存的分析。
- API 虽然调用 `saveAnalysis`，但 Vercel 上写入的是运行实例的临时 SQLite，无法作为跨刷新、跨实例和跨部署的持久存储。
- 原查询只读取全站最新分析，没有按站点和日期范围隔离。

## 修复

- 新增独立分析结果存储模块，按 `site + startDate + endDate` 生成稳定存储键。
- Vercel 生产环境保存到私有 Blob，本机保存到 SQLite。
- 分析页面在服务端读取对应结果，再作为初始值传给交互组件。
- 保存原分析问题；线上刷新后同时恢复问题和分析结果。
- 不同站点和日期范围使用不同记录，避免结果串站或串日期。

## 验证

- 本机独立临时 SQLite：生成分析后重新请求页面，成功恢复相同标题；临时数据库已删除。
- 生产 Vercel：API 返回 `persisted=true`，刷新页面后恢复相同标题和问题。
- 隔离验证：切换到其他站点或其他日期范围时，不会显示本次 FKK 分析。

## 状态

- 已修复、已发布、已完成线上真实链路验证。
