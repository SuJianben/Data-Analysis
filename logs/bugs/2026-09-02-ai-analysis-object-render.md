# BUG：AI 分析页面无法加载

## 日期

2026-09-02

## 复现条件

第三方 AI 返回 JSON 时，将约定为字符串的 `summary` 返回为嵌套对象。结果入库后，访问 `/analysis` 时 React 尝试直接渲染对象。

## 影响范围

AI 分析接口调用成功，但分析页面返回500，浏览器显示页面无法加载。

## 根本原因

连接器只解析 JSON，没有在持久化之前校验并规范化第三方模型输出；页面层也缺少对历史异常记录的显示兜底。

## 修复

- AI 连接器对标题、摘要、发现、严重级别和行动建议统一规范化
- 对结构化对象转换为可读文本后再入库
- 限制发现和行动建议数量
- 页面展示层增加安全文本转换，兼容已经存在的旧异常记录

## 状态

已修复并完成真实链路回归。

## 验证

- TypeScript 类型检查通过
- Next.js 生产构建通过
- `/analysis` 直接访问返回200
- 从概览页面点击“AI 分析”可正常进入
- 旧的对象型摘要可安全显示
- 重新点击“生成分析”后，第三方 AI 结果完成规范化并正常展示
