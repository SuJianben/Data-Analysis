# 2026-09-08 删除网站数据源页面

## 本次目标

删除网站中无法在腾讯云直接使用的手动数据源页面，避免用户继续触发必然超时的腾讯云 GA4 同步请求。

## 修改范围

- 删除侧边栏“数据源”入口和顶部“同步数据”按钮。
- 删除 `/sources` 页面及其专用表单组件。
- 保留 GA4、Clarity、标准化导入等后台接口，继续支持 Codex 本机自动同步。
- 清理概览页和本地分析结果中指向数据源页面的链接与文案。

## 新增内容

- 新增本次独立更新日志。

## 调整内容

- 概览页“最近同步”继续展示同步记录，但不再提供手动数据源入口。
- Clarity 缺少 Token 的错误信息改为直接提示环境变量配置。

## 影响范围

- 网站不再显示数据源配置页面，直接访问 `/sources` 将返回 404。
- Codex 自动化、本机同步脚本、`/api/sync/ga4` 和 `/api/import` 不受影响。
- 已保存的 OAuth 与导入密钥未删除，也没有写入代码仓库。

## 自检结果

- 清理旧 `.next` 路由缓存后，Next.js 生产构建通过。
- TypeScript 类型检查通过。
- 构建路由清单中已不存在 `/sources`。
- 腾讯云已完成全新构建并重启 `tkf-signal` 服务，健康检查返回正常。
- 公网首页已确认不再出现“数据源”、“同步数据”和 `/sources` 链接。
- 公网直接访问 `/sources` 返回 404。
- 数据库健康检查仍返回 66 条菜单数据、63 条指标数据和 15 个快照，本次下线未删除业务数据。

## 遗留问题

- 无。

- 线上源码与 GitHub 当前基线存在差异，因此未盲目覆盖整个项目，而是根据服务器实际代码精确删除相关入口和页面。
- 第一次线上校验发现首页仍有旧版链接，进一步读取实际源码后，确认服务器的 `app-shell` 和概览页仍保留两处入口；已精确删除并完成全新构建。
