# 2026-09-14 Shopify Pixel 购买归因接收修复

## 本次目标

- 修复 TMS 已有 GA4 购买记录、但用户行为 D1 没有 `purchase` 的问题。
- 保持普通浏览器埋点来源白名单不变，避免直接公开所有不透明来源写入。

## 修改范围

- Cloudflare 用户事件 Worker 的请求授权与购买事件校验。
- Worker 运维说明和既有购买归因 BUG 记录。
- 未修改面板页面、GA4 同步逻辑、主题点击埋点或数据库结构。

## 新增内容

- 新增 `src/shopify-pixel-ingest.ts`，集中校验 Shopify 沙箱购买事件。
- 校验站点与来源映射、单事件限制、购买事件名称、结账完成目标、订单 SHA-256 哈希、金额、币种、商品数量及事件时间窗口。

## 调整内容

- `POST /v1/events` 继续允许正式店铺域名和服务器密钥写入。
- 对 `Origin: null` 不做普通白名单放行，只在载荷通过 Shopify 购买专用校验时接收。
- 其他不透明来源事件继续返回 403；数据库原有唯一键继续负责重复事件去重。

## 影响范围

- TMS 与 TKF 的 Shopify Customer Pixel 购买桥接共用该修复。
- 历史被拒绝且未进入 D1 的购买事件不能从 GA4 汇总反推出具体用户。
- 后续真实 `checkout_completed` 可进入用户行为链，并按现有匿名访客/客户哈希规则归并。
