# 2026-09-09 数据表格分页

## 本次目标

为菜单分析、全局埋点和用户行为页面增加分页，避免一次性在一个页面铺满几百条信息。

## 修改范围

- 通用数据分页组件；
- 三个数据表格组件；
- 桌面端和移动端分页样式。

## 完成内容

- 新增 `src/components/data-table/pagination.tsx`，统一显示当前条数、总条数、当前页和上一页/下一页操作。
- 菜单分析、全局埋点、用户行为默认每页20条。
- 菜单搜索、全局埋点搜索和设备筛选变化时自动回到第1页。
- 日期范围切换导致数据更新时也会自动回到第1页。
- 分页仅影响展示，不改变真实数据合计和数据库来源。

## 自检结果

- 主项目 TypeScript 检查通过。
- 生产构建通过。
- 菜单分析共24条，已验证第1页20条、第2页4条；全局埋点共689条，显示为35页；用户行为共20条，显示为1页。
- 线上验证时发现用户行为日期在服务端与浏览器格式不一致会触发 React 水合错误，已改为固定使用 Asia/Shanghai 时区格式化。
- 修复后重新部署并复测，三个页面均可按20条分页浏览，用户行为页浏览器控制台无错误或警告。
- 空数据时仍保留原有空状态，不显示无意义的页码。
- 移动端分页按钮会改为纵向排列，避免横向溢出。

## 遗留问题

- 当前分页在前端完成，接口仍会读取当前时间范围内的全部行；如未来单站点数据量达到数万行，再升级为 Worker/D1 的服务端分页。
