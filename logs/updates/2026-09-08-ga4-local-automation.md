# 2026-09-08 GA4 本机自动同步

## 本次目标

通过 Codex 自动化在本机读取 GA4 真实数据，并上传到腾讯云 TKF Signal 数据面板。

## 修改范围

- 新增本机 GA4 到腾讯云的同步脚本。
- 为标准化数据导入接口增加可选密钥鉴权。
- 增加自动同步所需环境变量和运行命令说明。
- 创建每天执行的 Codex 自动化任务。

## 新增内容

- `scripts/sync-ga4-to-tencent.mjs`：调用本机 GA4 同步接口，整理返回数据，并上传腾讯云 `/api/import`。
- `npm run sync:ga4-to-tencent`：执行最近三天数据同步。
- `IMPORT_INGEST_KEY`、`TKF_IMPORT_URL`、`TKF_IMPORT_KEY`、`LOCAL_SYNC_URL` 配置说明。

## 调整内容

- `/api/import` 在服务端配置 `IMPORT_INGEST_KEY` 后，要求请求携带 `x-tkf-import-key`。
- 自动同步默认读取昨天及之前共三天的数据，降低 GA4 数据延迟造成的漏数风险。
- 脚本增加日期校验、请求超时、非 JSON 响应识别和明确的失败阶段输出。

## 影响范围

- 本地 GA4 同步接口和数据库保存逻辑未改变。
- 腾讯云当前旧版本接口仍可接收数据；部署本次代码并配置密钥后才会强制鉴权。
- 重复同步相同日期会通过数据库唯一约束更新汇总值，不会累计制造重复点击。
