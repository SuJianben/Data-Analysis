# 2026-09-10 四象限十字线居中调整

## 本次目标

- 按页面标注将散点图十字线固定在绘图区中心，使四个象限等宽、等高。

## 修改范围

- 修改公共散点图组件 `src/components/data-chart/distribution-scatter.tsx`。
- 菜单分析、全局埋点和用户行为三个页面通过公共组件同步生效。

## 新增内容

- 新增本次调整的日期更新日志。
- 未新增业务组件或第三方依赖。

## 调整内容

- 横轴与纵轴分界值由数据平均值改为各自显示区间的 50% 中点。
- 十字线位置固定为绘图区几何中心。
- 四个象限背景改为相同半宽、半高绘制。
- 散点颜色分类同步使用区间中点，避免十字线和点颜色的分类口径不一致。
- 页面说明由“虚线为当前范围平均值”改为“虚线为区间中线”。
- 后续真实页面验收发现：仅把十字线居中时，原始线性坐标仍会被少数极大值拉伸，大部分散点继续堆叠在左下角。
- 散点位置改为按横纵指标的相对百分位排名计算，50% 排名中位线与十字线保持一致。
- 对原始指标完全相同的点增加受象限边界约束的稳定错位，避免多项数据完全重叠；鼠标提示继续显示真实点击数、覆盖数等原始值。
- 横纵轴端点改为“低 / 高”，轴说明增加“相对排名”，避免把排名坐标误读为原始数值刻度。
- 修复基础 CSS 覆盖圆点动态颜色的问题，四个象限现在按各自图例颜色显示。

## 影响范围

- 只影响三张分布散点图的象限划分、十字线位置和说明文案。
- 不影响原始数据、日期筛选、列表、趋势图或设备构成图。
