# 2026-09-09 概览图表扩展

## 本次目标

扩展概览页的数据表达方式，不再只展示菜单点击趋势；图表类型参考用户提供的示例，但保持 TKF Signal 现有工作台风格。

## 修改范围

- 概览数据类型与本机 SQLite 聚合查询；
- Cloudflare D1 概览聚合查询；
- 概览页图表组合与响应式样式；
- 四个独立图表组件：流量柱状图、设备环形图、转化漏斗、页面入口排行。

## 新增内容

- 期间流量：页面浏览、访问用户、会话按日期柱状展示；
- 设备构成：按设备类别展示真实访问用户分布；
- 转化路径：页面浏览、加入购物车、开始结账、完成购买及阶段转化率；
- 页面入口点击：按真实全局埋点 pagePath 聚合排行。

## 调整内容

- 原有菜单点击趋势、高频菜单和最近同步继续保留；
- 所有图表联动顶部日期范围；
- 图表悬停显示日期、指标和数值，缺少数据时显示正式空状态；
- 某个指标在所选范围内完全没有真实数据时，图表会自动隐藏该系列，避免把全 0 误读为有效统计；
- 设备名称统一中文显示，保留未识别设备的可追溯性。

## 影响范围

- 概览页视觉信息量增加；
- 本机数据源与 Cloudflare D1 返回结构保持一致；
- 未改动 GA4 导入字段、埋点逻辑和其他明细页。

## 自检结果

- 主项目 `npm run typecheck` 通过；
- 主项目 `npm run build` 通过；
- Worker `npm run typecheck` 通过；
- Cloudflare Worker 已发布；
- Vercel 生产环境已发布；
- 线上概览已验证四种新增图表均读取真实数据，浏览器控制台无错误或警告。

## 遗留问题

- 当前图表数据仍随概览请求一次性读取当前日期范围；数据量显著增长后，可再按图表接口拆分或增加服务端聚合缓存。

## 后续修正

- 调整流量柱状图横轴：14天以内逐日标注，较长范围按5天或15天间隔标注，并按柱子位置对齐，避免日期与柱状数据产生视觉错位。
